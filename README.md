
# Ecommerce Website

## Project Description
This is an Ecommerce Website developed using React JS and React Router DOM.

The website allows users to navigate between different pages.

## Technologies Used
- HTML
- CSS
- JavaScript
- React JS
- React Router DOM
- Vite

## Features
- Header Section
- Navigation Menu
- Sidebar Categories
- Home Page
- Products Page
- About Page
- Contact Page
- Footer Section
- Page Navigation using React Router DOM

## Project Structure
- App.jsx
- App.css
- main.jsx

## Installation

1. Clone the repository.
2. Install dependencies:

npm install

3. Install React Router DOM:

npm install react-router-dom

4. Run the project:

npm run dev

## Output
Ecommerce Website with Header, Menu, Sidebar, Page Body and Footer.
